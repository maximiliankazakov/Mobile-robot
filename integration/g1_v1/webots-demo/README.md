# Живое демо G1 в Webots

Демо открывает обычное графическое окно Webots R2025a. Внутри одного Docker-контейнера работают симулятор TIAGo, два локализатора C++ и контроллер маршрута с защитой. A и B получают живые энкодеры, IMU и LiDAR. Контроллер следует по позе B, а A наблюдает тот же проезд. Эталон Webots читается отдельным оценщиком.

## Запуск готового образа

Нужен Linux x86‑64 с рабочим столом X11 либо XWayland, Docker и `xauth`. Проверенный запуск использует пользовательский Docker, X11 и Mesa на AMD. Для запуска в обычном режиме скачайте два файла в одну папку:

- `g1_webots_demo_linux_amd64.tar.gz`
- `run_webots_demo.sh`

Из терминала рабочего стола выполните:

```bash
bash run_webots_demo.sh
```

Первый запуск импортирует образ, последующие сразу открывают Webots. Приложение и зависимости уже внутри контейнера. Через несколько секунд после открытия сцены робот стартует автоматически по готовности ROS 2 и проходит две точки. В терминале появятся время, число достигнутых точек и принятые поправки A/B. Для повтора закройте окно Webots и снова выполните команду. Для запуска без видеокарты есть `G1_SOFTWARE=1 bash run_webots_demo.sh`. Скорость в этом режиме зависит от CPU. Для сохранения журналов установите `G1_OUTPUT_DIR` в путь к доступной на запись папке.

Сцена работает в изолированной Docker-сети. На рабочий стол передаётся окно через X11, а `/dev/dri` используется для ускорения графики на поддерживаемом Linux. При использовании Docker Desktop на Windows или macOS понадобится отдельная настройка графического вывода.

## Сборка из Git

Возьмите тег `g1-hw1-webots-v1`, распакуйте `g1_hw1_replay.tar.zst` и передайте путь к каталогу `bundle`. Первый build скачивает и проверяет архив Webots R2025a, если базовый образ симулятора курса ещё не собран. Готовый образ включает одну замороженную карту, модель B, проверенный маршрут `g1-test_0-nominal-06` и локальные ресурсы сцены.

```bash
bash integration/g1_v1/webots-demo/build.sh /path/to/bundle
bash integration/g1_v1/webots-demo/run_webots_demo.sh
```

Для G1 отключена RGB‑D камера. Валидация курса по всем 100 записям описана в [инструкции A/B replay](../portable/README.md). Живое демо проверяет короткий маршрут G1 с защитой G4 в Webots. Сквозная складская миссия G1–G5 относится к командному стенду.
